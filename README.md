# Analysis code for MSc thesis on chronic non-specific low back pain

This repository contains the public analysis script used for the MSc thesis investigating associations between pain intensity, body perception disturbance, and tactile acuity in individuals with chronic non-specific low back pain.

## Contents

- `02_analysis_CLBP_main_public_clean.R`: R script for data preparation, variable harmonisation, descriptive analyses, correlation analyses, multiple linear regression models, sensitivity analysis, tables, and supplementary figures.

## Data availability

The datasets analysed in this project are not included in this repository due to ethical, contractual, and data governance restrictions. The Australian RESOLVE dataset was accessed and analysed within a secure institutional environment and could not be downloaded, transferred, or redistributed. The Swiss dataset is likewise not publicly available to protect participant confidentiality.

The script therefore contains placeholder file paths. Running the script requires authorised access to the original datasets.

## Software

The analyses were conducted in R. The script uses the following R packages:

- tidyverse
- janitor
- readr
- readxl
- broom
- car
- gtsummary
- flextable
- officer
- gridExtra

## Notes

This repository is intended to support transparency of the analysis workflow. It does not contain raw data, participant-level data, consent forms, ethics documents, or any confidential project material.
